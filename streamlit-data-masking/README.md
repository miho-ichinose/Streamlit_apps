# データマスキング専用ツール

大容量CSVファイルにも対応した、高機能なデータマスキングツールです。個人情報や機密情報を適切にマスキングし、プライバシー保護とデータ活用の両立を実現します。

## 🚀 クイックスタート

### 1. 必要なライブラリのインストール
```bash
pip install streamlit pandas openpyxl xlsxwriter
```

### 2. アプリケーションの起動
```bash
streamlit run data_masking.py
```

### 3. ブラウザで自動的に開きます
通常は `http://localhost:8501` でアクセス可能

## 📋 基本的な使い方

### ステップ1: ファイルの指定
1. ローカルファイルパスを入力（例: `C:/data/customer_data.csv`）
2. ファイルが自動で読み込まれ、プレビューが表示されます

### ステップ2: マスキング設定
**サイドバーで以下を設定：**

1. **対象列を選択** - マスキングしたい列を複数選択可能
2. **マスキング方式を選択**
3. **プレビュー確認** - 「👀 プレビューにマスク適用」ボタンで事前確認

### ステップ3: 実行
「▶ ストリーミングでマスクして保存」ボタンをクリック

## 🛡️ マスキング方式

### 1. 全マスク(****)
すべての文字を`****`に置換
```
田中太郎 → ****
```

### 2. 先頭N/末尾M以外マスク
指定文字数だけ残してマスク
```
田中太郎 → 田***郎  (先頭1、末尾1の場合)
```

### 3. SHA256ハッシュ
不可逆的にハッシュ化（ソルト追加可能）
```
田中太郎 → a8f5f167f44f4964e6c998dee827110c
```

### 4. トークン化
一意のトークンに置換（マッピング保存可能）
```
田中太郎 → TKN_0000001
```

### 5. 正規表現マスク
パターンに一致する部分のみマスク
```
正規表現: \d{4}
1234-5678 → ****-****
```

### 6. プリセット

#### 📧 Email
ドメイン部分をマスク
```
tanaka@example.com → tanaka@*********
```

#### 📱 Phone
中間番号をマスク
```
090-1234-5678 → 090-****-5678
```

#### 💳 CreditCard
最後4桁以外をマスク
```
1234-5678-9012-3456 → ************3456
```

#### 🏠 住所（都道府県まで）
都道府県のみ残す
```
189-9674 東京都墨田区押上1-1-2 → 東京都
```

#### 🏠 住所（市区町村まで）
市区町村まで残す
```
189-9674 東京都墨田区押上1-1-2 → 東京都墨田区
```

## 💾 大容量ファイル対応

### ストリーミング処理
- **チャンクサイズ調整可能**（デフォルト: 100,000行）
- メモリ効率的な処理で数GB規模のファイルも処理可能
- 処理状況をリアルタイム表示

### 対応フォーマット
- CSV / TSV
- Excel（.xlsx, .xls）
- Gzip圧縮ファイル（.csv.gz, .tsv.gz）

## 📁 出力ファイル

### 1. マスキング済みデータ
- 元ファイル名に`_masked`を付加
- 同じフォルダまたは指定フォルダに保存
- CSV出力時はgzip圧縮オプションあり

### 2. トークンマップ（JSON）
トークン化使用時の対応表
```json
{
  "田中太郎": "TKN_0000001",
  "佐藤花子": "TKN_0000002"
}
```

### 3. 実行ポリシー（JSON）
監査用の実行設定記録
```json
{
  "columns": ["名前", "住所"],
  "method": "全マスク(****)",
  "timestamp": "2024-01-01 10:00:00"
}
```

## 🔧 高度な設定

### サイドバーオプション
- **ヘッダ行の有無** - CSVの1行目が列名かどうか
- **プレビュー行数** - 表示する行数（5～5000）
- **チャンクサイズ** - ストリーミング処理の分割単位
- **出力先フォルダ** - 保存先の指定
- **gzip圧縮** - CSV出力を圧縮

### トークンマップの再利用
1. 既存のトークンマップ（JSON）を読み込み可能
2. 同じトークンを維持してマスキング継続
3. 新規データは自動的に新規トークン付与

## ⚠️ 注意事項

- **元ファイルは変更されません**（新規ファイルとして保存）
- **処理前に必ずプレビューで確認**してください
- 大容量ファイル処理時は十分な空きディスク容量を確保
- Excelファイルは全体読み込みのため、超大容量には不向き

## 🆘 トラブルシューティング

### ファイルが読み込めない
- ファイルパスが正しいか確認
- ファイルが他のアプリで開かれていないか確認
- 文字コードの問題の場合、CSVをUTF-8で保存し直す

### メモリ不足エラー
- チャンクサイズを小さくする（例: 50,000行）
- Excelファイルの場合はCSVに変換
- プレビュー行数を減らす

### 住所マスキングがうまくいかない
- 住所が標準的な形式（都道府県名から始まる）か確認
- 郵便番号付きでも自動対応しますが、特殊な形式は要調整

---

**開発者向け情報**: コードのカスタマイズが必要な場合は、正規表現パターンやプリセット関数を`PRESETS`辞書に追加することで、独自のマスキングパターンを実装できます。
